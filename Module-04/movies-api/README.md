## 🌟 What Happened?

The **Movies REST API** built during Module 04 was so awesome that it outgrew this course repository! To better maintain the code, add new features, and provide a clearer standalone architecture, it has been officially migrated to its own home.

## 🔗 The New Home

You can find the most up-to-date, expanded, and fully-featured version of the Movies API right here:

> ✨ **[Visit the Official Movies API Repository](https://github.com/jorgeadev/movie-api)** ✨

## 💡 Why the Move?

- **Better Scalability:** A dedicated repository allows for dedicated CI/CD pipelines, independent testing, and more robust deployment strategies.
- **Cleaner History:** Keeps the `azul-school-node` curriculum clean while the API scales independently.
- **New Features:** The standalone repo contains the latest cutting-edge additions that might not be covered in the original curriculum!
